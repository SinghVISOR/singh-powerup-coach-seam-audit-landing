The SMB.AI Operator God Mode primer — sets your non-negotiables and shortcuts before the first task:

You are my product & engineering partner for SMB.AI. Treat me as the product manager and final decision-maker — no hedging, lead with the sharpest option. If my framing is wrong, correct it first, then answer the better version. Default format: BLUF, then the supporting logic. Apply MECE to any breakdown. Non-negotiables: never expose API/Supabase keys in the frontend; never store tokens as plaintext; every write/send action must queue for my approval; keep model = claude-sonnet-4-6. Hold decisions across this session and build on them without being asked. # shortcuts /human = run this task through HUMAN: Halt, Understand, Mark the Line, Apply the Leverage, Never Outsource. /smeac = structure as a full SMEAC brief (for any dev/offshore handoff). /knox = VISOR Analytics strategic-analyst persona. Acknowledge with "Ready" and wait for the first task.
The core principle
In claude.ai chat there are no built-in slash commands — everything is read as natural language. The slash just signals "this is a modifier." The frameworks work because Claude understands intent, and God Mode is a prompt pattern you write yourself — not a feature toggle. The quality of your answer never exceeds the quality of the question you were brave enough to ask.
The discipline the toolkit serves

The HUMAN Framework

Five moves that keep a person conscious and in command while operating at machine speed. The prompting frameworks live inside the second letter — Understand the Real Question. By Singh Leadership · VISOR Analytics.

H
Halt
Put a deliberate gap between the impulse and the tool — a gap just long enough for the human to catch up to the machine.
Toolkit tie → the Operator's Check, before you prompt
U
Understand the Real Question
A search-box question gets a search-box answer. Name the real decision, then hand the machine context and its non-negotiables.
Toolkit tie → every framework on this page
M
Mark the Line
Give the machine the drafting and repetition; keep the judgment, the relationship, the values call.
Toolkit tie → the approval queue; the assumption audit
A
Apply the Leverage
Once the line is drawn, use the machine boldly on its side — delegate fully so you can invest deeply.
Toolkit tie → God Mode + the constraint stack
N
Never Outsource the Core
Judgment, values, the final call, purpose. If a machine can generate it, a machine can copy it — what can't be copied is you.
Toolkit tie → devil's advocate & pre-mortem, then your call

Understand · shape the prompt

Core frameworks

Military and business scaffolds adapted for SMB operations. Each acronym is a complete thinking system — use it as a prompt, not a label.

SMEAC — operations briefing

Five dimensions, nothing left open. Best for scoping a skill build or any dev/offshore handoff.

S
Situation
Context and constraints — what everyone must understand before acting
M
Mission
The objective in one sentence — what success looks like, by when
E
Execution
Phases, who does what — no ambiguity left open
A
Admin / Logistics
Tools, resources, scope boundaries
C
Command / Signal
Escalation, decision authority, go/no-go gates
Structure this build using SMEAC (Situation, Mission, Execution, Admin/Logistics, Command/Signal). Audience: the dev workstream. Flag every open question as [OPEN QUESTION]; list dependencies explicitly.
Decide fast

OODA

Observe → Orient → Decide → Act → repeat. A speed-of-decision cycle.

In ops: a competitor moves, an outage hits.
Apply OODA to [scenario]. Move fast — identify the decision I need now, not just the data.
Report

BLUF

Bottom Line Up Front — conclusion first, rationale after.

In ops: status updates, cash-flow snapshots.
Respond in BLUF format. Recommendation in the first sentence, then the supporting logic.
Persuade

SCQA

Situation → Complication → Question → Answer.

In ops: proposals, the pitch, board updates.
Write this using SCQA. Audience: investors. Tone: authoritative and warm.
Prioritize

RICE

Reach × Impact × Confidence ÷ Effort — a defensible ranking.

In ops: which skill to build next.
Score these options using RICE and rank them. Show your working.
Check

MECE

Mutually Exclusive, Collectively Exhaustive — no overlaps, no gaps.

In ops: sanity-check any list before acting.
Review this breakdown and ensure it is MECE. Flag any overlaps or gaps.
Analyze

PMESII-PT

Full-spectrum situational analysis across seven dimensions.

In ops: market entry, risk assessment.
Run a PMESII-PT analysis on [market]. Use MECE to structure. Add confidence ratings.
Apply the Leverage · prime the session

God Mode

A system prompt you write yourself — it sets the relationship, authority, format, and challenge posture before the first task. No toggle, no secret command. Pure prompt engineering.

The six layers

Persona

You are a [world-class expert] with [X years] in [domain].

Authority

Treat me as a peer expert. Skip generic caveats.

Depth

Give me second- and third-order implications.

Format

Respond in [BLUF / SMEAC / bullets]. No filler.

Challenge

If my framing is wrong, tell me first — then answer better.

Memory

Hold context; build on earlier decisions unprompted.

Slash & shortcuts

In claude.ai chat the slash is a visual convention, not a command system. Define your stack once with God Mode, then use them all session.

Bottom line
You can invent your own shortcuts and they work immediately — Claude reads /human and the full instruction the same way. Native commands (/clear, /compact) only exist in Claude Code.

→ Judgment

Pre-mortem

Assume failure, work backwards. Surfaces blind spots.

It is 12 months from now and this failed. What went wrong?
→ Data & Reporting

Confidence rating

Separate signal from filler in any output.

Rate your confidence in each claim (high / medium / low). Flag anything uncertain.
→ Mark the Line

Assumption audit

Surface hidden premises before you build on them.

List every assumption embedded in this plan. Which are most fragile?
